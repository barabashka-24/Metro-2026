# **Metro 2026** — Справочник по Петербургскому метрополитену

Приложение-энциклопедия для Android (>8), которое рассказывает об истории станций и электропоездов Петербургского метро

- **Интерактивная карта** — интерактивная схема метро 2026 года
- **Список станций** — cтатьи о станциях Петербургского метрополитена
- **Электропоезда** — статьи о всех электропоездах, числившихся в подвижном составе метро СПб
- **История метро СПб** — с 1955 до 2026
- **Тёмная тема** — ручное переключение светлой и тёмной тем, а также режим «Как в системе»
- **Полный офлайн** — все данные хранятся локально

## Запуск проекта
### Смартфон Android
Просмотрите папку "Releases" на страничке проекта или перейдите по ссылке в низу README в магазин приложений RuStore.
### Android Studio
1. Склонируйте репозиторий:  
   `git clone https://github.com/barabashka-24/Metro-2026`
2. Откройте папку в Android Studio.
3. Запустите на эмуляторе или устройстве (minSdk = 26).
