**Metro2026** — Справочник по Петербургскому метрополитену

Приложение-энциклопедия для Android (>10), которое рассказывает об истории станций и электропоездов Петербургского метро

- **🗺️ Интерактивная карта** — схема метро 2026 года
- **🚉 Список станций** — cтатьи о станциях Петербургского метрополитена
- **🚃 Электропоезда** — Статьи о всех электропоездах, числившихся в подвижном составе метро СПб
- **📖 История метро СПб** — с 1955 до 2026
- **🎨 Тёмная тема** — ручное переключение светлой и тёмной тем, а также режим «Как в системе»
- **Полный офлайн** — все данные хранятся локально

1. Склонируйте репозиторий:

2. Откройте папку в Android Studio.
3. Запустите на эмуляторе или устройстве (minSdk = 29).
